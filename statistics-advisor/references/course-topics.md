# Course topics

The skill has a companion course, a separate project of plain-language explainers, hands-on how-to guides and notebooks for master's students in the life sciences. You cannot read the course or link to it from here. When an answer touches one of these topics, **name the matching page by module and title** (for example: *the course page "Multicollinearity" in module 6, Building Models*), so the user can find it with the course's sidebar search. Choose only titles from this list and never invent one.

Pages that have a hands-on recipe end with a "Do it yourself" box leading to the how-to guide or notebook, so naming the topic page is enough. The how-to guides are listed below because they are what to name when the user asks *how to do* something in Python; mention that the guide is reachable from the topic page.

Format (kept machine-checkable against the course): one page title per bullet, indented under its module heading. Page titles are the course's sidebar titles.

## Which page for which situation
- The user cannot run generated code or notebooks, or asks how to install Python or VS Code: "Set up your computer".
- The user asks how to structure folders, keep raw data safe or use Git: "Organize your project".
- The user asks how to install this skill or use an AI agent: "Work with an AI agent".
- The user wants a one-page map of the whole decision process: "Workflow Cheatsheet".
- The user wants to combine the results of several studies, or asks about heterogeneity, forest or funnel plots, or publication bias: "Meta-analysis" and "Meta-analysis: bias and pitfalls" in module 7 (the guide "How to: run a meta-analysis" is reachable from the first).
- The user does not know a term: "Glossary".
