# Module 4: Regression Basics

Regression underlies almost every test in Module 3, and every model later in this course. This module explains the core idea on its own terms.

2. [Tests as regressions](./tests-as-regressions.md) — how the "named" tests from Module 3 are all regression in disguise.
3. [Generalized linear models (GLMs)](./generalized-linear-models.md) — extending regression to yes/no outcomes and counts.
