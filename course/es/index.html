Curso de estadística para científicos de la vida

Un curso práctico de estadística para estudiantes de máster en ciencias de la vida.

Cada tema es una página breve y autocontenida. No hace falta que sigas el orden de la barra lateral. De hecho, probablemente la mejor manera de moverte por el curso sea ir directamente a la Guía rápida del flujo de trabajo y, siguiendo el árbol de decisión, elegir los temas que más te interesen. También puedes buscar cualquier tema en el buscador y seguir los enlaces para descubrir temas relacionados. Y si hay algún término que no reconoces, tienes el Glosario. Sigue además las instrucciones de Prepara tu ordenador para dejar todo instalado y listo para el curso. Y si quieres crear una carpeta de proyecto para tus análisis, consulta Organiza tu proyecto. El curso incluye un asistente de IA especializado que te ayuda con los análisis. Si quieres usarlo, consulta Trabaja con un agente de IA.

A lo largo del curso seguiremos dos ejemplos recurrentes:

  • Mia, una estudiante de genética clínica que investiga si una variante de un gen del colesterol (LDLR) está asociada al colesterol LDL.
  • Theo, que está comprobando si un nuevo fármaco reduce la presión arterial.

Sus historias se van concretando a medida que avanzan los módulos, de modo que los mismos conceptos reaparecen en un contexto familiar.

Sugerencia Consulta la Guía rápida del flujo de trabajo, una vista en una página del árbol de decisión de todo el proceso, antes de sumergirte en cada módulo.

Aplica lo que aprendes

Las páginas de temas explican el porqué. Cuando hay una receta práctica, la página termina con un cuadro Hazlo tú mismo que enlaza con una guía breve (pasos, código Python para copiar y pegar, cómo leer los resultados y qué hacer si algo sale mal) y, a veces, con un cuaderno (notebook) para explorar la idea en la práctica. Las guías contienen los procedimientos que debes seguir, mientras que los cuadernos los muestran en acción con datos de ejemplo. Conviene que sigas la guía y el cuaderno a la vez, porque se complementan (y, por supuesto, que vuelvas a las páginas de temas para repasar los conceptos). Las guías prácticas también aparecen en la página de inicio de cada módulo. Actualmente cubren:

  • Planificar un tamaño muestral
  • Explorar un conjunto de datos
  • Ejecutar una prueba habitual y comprobar sus supuestos
  • Ejecutar una prueba como regresión
  • Dibujar y usar un diagrama causal
  • Validar un modelo predictivo, comprobar la multicolinealidad y corregir el error de medición
  • Analizar datos agrupados y realizar un metaanálisis

El código está en Python (pandas, statsmodels, scikit-learn, matplotlib). ¿Es la primera vez que lo ejecutas? Prepara tu ordenador te guía paso a paso para instalarlo todo en Windows, macOS o Linux, y Organiza tu proyecto propone cómo estructurar un análisis. Para usar un asistente de IA (y la skill statistics-advisor) con el curso, consulta Trabaja con un agente de IA. Los cuadernos están en notebooks/; descarga uno y ábrelo en Jupyter, VS Code o Google Colab.
